# СТАЛЬТРАССА

Сайт металлических кабельных лотков: главная, каталог, страницы серий, доставка и оплата, контакты.

Нужен Node.js 22. База данных не нужна: заявки сохраняются в браузере.

## Локальный запуск

```bash
npm install
npm run dev
```

Сайт откроется на `http://127.0.0.1:8080`.

Проверка типов: `npm run typecheck`.

## Сборка

```bash
npm install
npm run build
npm run preview
```

`npm run build` собирает клиент и сервер в формате Vercel. Без `DATABASE_URL` миграции пропускаются — для этого сайта это нормально.

`npm run preview` поднимает собранную версию на `http://127.0.0.1:8081`.

## Настройка Vercel

Сайт собирается пресетом Nitro `vercel`: команда `npm run build` сама пишет `.vercel/output`. Отдельный каталог `dist` указывать не нужно.

### Первый проект

1. Войдите на [vercel.com](https://vercel.com) под аккаунтом, у которого есть доступ к GitHub `Krapivin1986`.
2. **Add New → Project** и импортируйте [Krapivin1986/staltrassa](https://github.com/Krapivin1986/staltrassa). Если репозитория нет в списке, нажмите **Adjust GitHub App Permissions** и разрешите доступ к нему.
3. На экране настройки оставьте:
   - **Framework Preset** — `Other`. Не выбирайте Next.js: это не Next-проект.
   - **Root Directory** — корень репозитория, `./`.
4. Раскройте **Build and Output Settings** и проверьте команды:

   | Поле | Значение |
   | --- | --- |
   | Install Command | `npm install --omit=dev --no-audit --no-fund` |
   | Build Command | `npm run build` |
   | Output Directory | пусто |

   Install Command уже задан в `vercel.json`. Если поле пустое, Vercel возьмёт его оттуда. Output Directory оставьте пустым: если указать `dist`, `public` или `.vercel/output`, деплой сломается.
5. Блок **Environment Variables** не заполняйте. Сайт работает без ключей. `DATABASE_URL` понадобится только если позже подключите Postgres.
6. Нажмите **Deploy** и дождитесь статуса Ready.

### После создания проекта

В **Settings → General** выставьте **Node.js Version** `22.x`. В **Settings → Git** производственная ветка должна быть `main`: пуш в неё запускает новый деплой сам.

Проверьте адреса:

- `/`
- `/catalog`
- `/catalog/perforated`
- `/catalog/ladder`
- `/catalog/solid`
- `/delivery`
- `/contacts`

Пока домен не подключён, сайт открывается на `*.vercel.app`.

## Домен

Домен подключается в уже задеплоенном проекте. Vercel сам выпустит сертификат, как только DNS станет верным.

1. Откройте проект и перейдите в **Settings → Domains**.
2. Нажмите **Add Domain** и введите домен, например `staltrassa.ru`. Vercel предложит добавить и `www`. Соглашайтесь: так оба адреса будут открывать сайт.
3. На карточке домена Vercel покажет нужные записи. Скопируйте их в панель регистратора (Reg.ru, Timeweb, Cloudflare и т.п.). Не берите IP из чужой инструкции: у проекта он свой.

   | Адрес | Тип | Имя | Значение |
   | --- | --- | --- | --- |
   | `staltrassa.ru` | A | `@` | IP со страницы Domains, часто `76.76.21.21` или `216.198.79.1` |
   | `www.staltrassa.ru` | CNAME | `www` | цель, которую показывает Vercel, вида `xxxx.vercel-dns-017.com` |

4. Старые A и CNAME для `@` и `www` удалите. Записи почты (MX, TXT для SPF) не трогайте.
5. Если домен уже был у другого аккаунта Vercel, добавьте TXT-запись на `_vercel` с текстом, который покажет панель.
6. Подождите от нескольких минут до суток. Статус должен смениться на **Valid Configuration**. После этого HTTPS включается сам.
7. На том адресе, который не основной, включите **Redirect**, чтобы `www` вёл на домен без `www` или наоборот.

Nameservers на `ns1.vercel-dns.com` и `ns2.vercel-dns.com` менять не нужно, если DNS и почта уже живут у регистратора. В Cloudflare на время проверки выключите прокси (серое облако): оранжевое прячет записи, и Vercel не видит их.


## Как менять текст

Тексты главной, серий, отзывов, контактов и доставки правятся в админке, а не в коде.

1. Откройте **Админка** в подвале сайта.
2. Войдите через Google или X.
3. Первый вошедший аккаунт становится администратором. Остальные вход видят, но сохранить текст не могут.
4. Измените поля и нажмите **Сохранить**. Страница обновится для всех посетителей.

На своём проекте Vercel задайте `DATABASE_URL` (Postgres). Без базы правки живут только до перезапуска сервера. Фото, размеры в таблицах и тарифы по-прежнему в коде.
